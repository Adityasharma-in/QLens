- **HARNESS TRAP (cost real time this session — read before adding tests).** `test(name, fn)` in `tests/unit/run.mjs` is **synchronous**: it calls `fn()` and never awaits the result. An `async` test registered with `test()` returns a promise that nobody awaits, so a failing assertion becomes an unhandled rejection — the suite prints `PASS`, the total excludes it, and the process still exits 0.
